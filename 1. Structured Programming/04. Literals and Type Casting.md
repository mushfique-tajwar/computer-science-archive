## Literals

Variables that are fixed to one data type. Example:- `a = int(10)`

## Type Casting

It refers to converting an object of one type to another.

- String to Integer: `a = int(‘100’)`
- String to Float: `a = float(‘100.0’)`
- Integer to Float: `a = float(100)`
- Integer to Binary: `a = bin(65)`
- Binary to Integer: `a = int(‘110011’, 2)`
- Octal to Integer: `a = int(‘20’, 8)`
- Hexadecimal to Integer: `a = int(‘2A9’, 16)`
- Integer to String: `a = str(10)`
- Float to String: `a = str(10.1)`
- String to List: `a = list(‘string’)`
- String to Tuple: `a = tuple(‘string’)`
- List to Tuple: `a = tuple([1,2,3])`
- Tuple to List: `a = list((1,2,3))`
- Tuple to String: `a = str((1,2,3))`
- List to String: `a = str([1,2,3])`
