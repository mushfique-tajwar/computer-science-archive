This chapter (folder) is mainly based on the programming language Python

Python is a high-level, interpreted, interactive and object-oriented scripting language. The extension of Python script is ‘py’. To run a python script, in terminal type `python3 file_name.py` (For windows, use python instead of python3)

### Virtual Environment

Virtual disposable installation of Python inside a project directory, so that it does not break packages in other environments.

How to install and use a python virtual environment:

- Install ‘venv’ module. `sudo apt update` then `sudo apt install python3-python3-pip python3-venv`
- Redirect to the project path `cd /path/to/your/project`
- Create the virtual environment `python3 -m venv .venv`
- Activate the environment `source .venv/bin/activate`
- Install libraries `pip install requests`
- Save dependencies to a file `pip freeze > requirements.txt`
- Install dependencies on another machine `pip install -r requirements.txt`
- Deactivate the environment “deactivate”

### Basic Syntax

- **Identifiers:** To identify a variable, function, class, module or other objects. (Must start with alphabets, upper or lower, or underscore, can contain numbers but not start with them)
- **Reserved Words:** and, or, if, else, elif, is, not, etc.
- **Lines and Indentation:** Code blocks must follow line indentations which are rigidly enforced.
- **Multi-Line Statements:** Use ‘\’. However, brackets do not need those.
- **Quotations:** Use ‘ ’, “ ” or ‘‘‘ ’’’. Triple quotes can be written into multiple lines.
- **Comments:** Use ‘#’ to comment.
