**Object-oriented programming (*OOP*)** is a programming paradigm that uses the concept of objects and classes to design and build applications. Python is a multi-paradigm language that fully supports object-oriented programming, making it simple to create and use classes and objects.

---

## Procedural-Oriented vs. Object-Oriented Approach

Early programming languages developed in the 1950s and 60s are recognized as procedural (or procedure-oriented) languages, where a computer program describes a procedure of performing a task by writing a series of instructions in a logical order, broken down into functions.

### Procedural-Oriented Approach
* **Top-down approach:** Makes complex programs difficult to maintain.
* **Global Data:** Uses many global data items, which increases memory overhead and allows unrestricted movement of data across functions.
* **Focus on Process:** Gives more importance to processes/functions rather than data.

### Object-Oriented Approach
* **Object-focused design:** Focuses on modeling real-world entities that combine both data (attributes) and behavior (functions/methods) into a single unit.
* **Data Hiding & Security:** Data cannot move freely from method to method; access can be controlled using public or private visibility rules.
* **Modularity and Reusability:** Enhances program modularity, making existing code easier to maintain and modify without disturbing other parts.

---

## Real-World Entities and Objects

In the real world, we deal with objects such as students, employees, invoices, cars, etc. An object is an instance of a class and consists of:
1. **Attributes (Data Members):** Characteristics or properties of an object (e.g., name, age, salary, speed).
2. **Behavior (Methods):** Actions or functions performed by or on the object (e.g., compute percentage, calculate incentives, measure speed).

---

## Principles of OOP Concepts

The object-oriented programming paradigm is characterized by the following fundamental principles:

1. **Class:** A user-defined prototype or blueprint for an object that defines a set of attributes (class variables, instance variables) and methods.
2. **Object:** An instance of a class that represents a specific real-world entity with actual values for its attributes.
3. **Encapsulation:** Binds data members and member functions into a single unit (class) and restricts direct access to some of an object's components to protect data integrity.
4. **Inheritance:** Allows a class (derived/child class) to acquire the properties and methods of another class (base/parent class), promoting code reusability.
5. **Polymorphism:** Allows the same function name, method, or operator to behave differently depending on the context or the object it is acting upon.
6. **Abstraction:** Hiding complex implementation details and showing only the essential features of an object.

---

## Checking Relationships and Instances

Python provides built-in functions to check relationships between classes and instances:

* `issubclass(sub, sup)`: Returns `True` if the given subclass `sub` is indeed a subclass of the superclass `sup`.
* `isinstance(obj, Class)`: Returns `True` if `obj` is an instance of class `Class` or an instance of a subclass of `Class`.
